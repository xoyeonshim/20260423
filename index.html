04 / PROCESS
자동화 프로세스

5단계로 끝.

01

시트 스캔

「알림대상」=TRUE 이고 「발송완료」가 아직 안 된 행만 대상자로 추출

「알림대상」은 계약 종료 6주(42일) 전부터 자동으로 켜집니다

=IF(ISNUMBER($J8), TODAY() >= $J8 - 42, FALSE)
02

수신자별 그룹화

같은 조직장에게 만료자가 N명이면 1통의 메일 + 표로 통합

03

조건 분기 본문 생성

'연장 가능' 여부에 따라 본문 내용 자동 선택

04

발송 + 시트 기록

메일 전송 성공 시 「발송완료」 체크 → 중복 발송 방지

05

슬랙 리포트

운영 담당자 채널에 성공·실패·상세 내역 자동 공유

04 / PROCESS
핵심 — 조건 분기

같은 트리거, 다른 메시지.

시트의 '비고' 한 칸이 발송될 메일 전체를 결정합니다.

CASE A

연장 가능

  • 본문: 계약 연장 안내 + 종료 안내
  • 내용: 연장 절차 · 마감일 · 급여 인상 가이드
  • 조직장 회신 요청 CTA
  • 참조: 운영 담당자
본문 종류
연장 안내 본문
CASE B

연장 불가

  • 본문: 계약 종료 안내 only
  • 종료 프로세스 · 자산 반납 · 정산 안내
  • 대체인력 충원 가이드 링크
  • 참조: 현업 조직장
본문 종류
종료 안내 본문
// 발송 본문을 정하는 규칙
같은 조직장 그룹의 전원이 '연장불가'  →  종료 안내 본문으로 발송
한 명이라도 연장 가능  →  연장 안내 본문으로 발송
※ 비고 텍스트의 최대 N개월, 연장불가, 연장계약 불가 표현은 메일 본문에서 자동으로 빨간색 강조됩니다.
